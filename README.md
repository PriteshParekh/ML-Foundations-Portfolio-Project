# ML-Foundations-Portfolio-Project

Conducting analysis on crime data posted by data.police.uk, using Jupiter Notebooks.

## Questions to explore:

# 1) Dataset overview

# 1. a. How many total crimes were recorded?
# 1. b. How many unique crime types are in the dataset?
# 1. c. Are there duplicate records in the dataset?

# 2) Crime type analysis

# 2. a. Which crime type occurs most often?
# 2. b. Which crime type occurs least often?

# 3) Monthly trends

# 3. a. How many crimes were recorded each month?
# 3. b. Which month had the highest crime count?
# 3. c. Which month had the lowest crime count?
# 3. d. How many unique crime types appear in each month?
# 3. e. Which month has the widest variety of crime types?

# 4) Reporter analysis

# 4. a. Which reporter recorded the most crimes overall?
# 4. b. Which reporter recorded the fewest crimes overall?
# 4. c. How many crimes did each reporter record each month?

# 5) Geographic analysis

# 5. a. Which location has the highest number of recorded crimes?
# 5. b. Which LSOA areas have the highest number of crimes?
